# Вход в существующий код

Маршрут рассчитан на новый проект: модуль «Идея» заводит папку с нуля. Этот файл
закрывает второй случай - в папке уже есть код, и человек хочет его дорабатывать.

## Когда включается

Проверяется в самом начале, до первого вопроса человеку. Признак живого кода - любой из:

- в папке есть `package.json`, `requirements.txt`, `pyproject.toml`, `go.mod`, `Gemfile`;
- есть каталог с исходниками (`app/`, `src/`, `lib/`) и в нём больше пяти файлов;
- `git log` возвращает хотя бы один коммит.

Ни одного признака - это новый проект, идём обычным маршрутом.

## Что делает разведка

Четыре читателя параллельно. Каждый только читает, ничего не пишет и не меняет.

| Читатель | Что выясняет |
|---|---|
| Устройство | какие папки, где точка входа, как запускается |
| Данные | какие сущности уже есть: модели, таблицы, `schema.prisma` |
| Проверки | чем проект проверяется: команда сборки, линт, тесты (это же паспорт среды) |
| Опасное | где деньги, персональные данные, отправка наружу, где лежат секреты |

Каждый возвращает не пересказ файлов, а вывод: что есть, где лежит, чего не хватает.

## Что появляется на диске

`architecture/00-karta-proekta.md` - карта существующего проекта:

- как устроено сейчас (по четырём разделам выше);
- какие сущности уже есть - это вход для шага 5.2, заново их не выдумываем;
- чем проверяется - это вход для гейтов;
- **чего не хватает** - список пробелов, которые придётся закрыть.

## Восстановление замысла

Дальше вместо «создать `idea/` с нуля» - восстановить замысел из кода и дать человеку
дополнить. Правило разметки, обязательное:

- **[из кода]** - выведено из того, что реально написано;
- **[со слов]** - сказал человек;
- **[догадка]** - предположение агента.

Через неделю выведенное и додуманное выглядят одинаково, поэтому метка ставится сразу.
Верность восстановленного ничем не измеряется - это честная догадка, а не факт.

## Границы

- Разведка отвечает на «что есть», а не на «почему так сделано». Намерение прошлого автора
  невосстановимо, если в проекте нет записей о решениях.
- Чужой репозиторий может не собираться изначально. Тогда фиксируем число падающих проверок
  и регрессией считаем только его рост, а не сам факт падения.
- Всё, что не перечислено в разделе «Опасное» явно, считается опасным по умолчанию.
  Перечислить всё рискованное в чужом проекте заранее нельзя.
